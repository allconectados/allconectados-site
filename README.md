# Allconectados

Plataforma educativa para apresentar agentes GPT e orientar professores na elaboração de documentos pedagógicos.

## Estrutura inicial

- página principal pública;
- apresentação dos agentes;
- página individual protegida por login;
- login com Google via Supabase;
- identidade visual inicial;
- preparação para área administrativa, dúvidas e fórum.

## Desenvolvimento local

1. Instale o Node.js.
2. Execute `npm install`.
3. Copie `.env.example` para `.env`.
4. Preencha as variáveis públicas do Supabase.
5. Execute `npm run dev`.

Não publique senhas, chaves secretas do Google ou a chave `service_role` do Supabase.
